## 1. Approved decisions

| # | Decision |
|---|---|
| D1 | Account data (personal + org) → PDF/CSV rendered **on the backend** with QuestPDF from the database (trustworthy, auditable, emailable later). Guests → **print-friendly analytics page** (browser "Save as PDF") + **CSV built in the browser**. |
| D2 | Report = "what I'm looking at": same Month / ISO-Week / Day selection as the analytics page; header with range, time zone, generated-at; light print styling; paper A4 or US Letter from the browser locale (with a small override). |
| D3 | Every export gets a **document ID** (`TP-yyyyMMdd-XXXXXXXX`), a "Generated by Time Planner on …" footer and a row in an append-only `ReportExports` table; org exports appear in the org activity feed. No digital signatures. |
| D4 | Permissions mirror the API: Owner/Admin export org reports and any member's report; members export only their own member report and their personal report. |
| D5 | Organizations get an IANA **time zone** (default = creator's zone; Owner/Admin can edit). Org analytics/reports bucket in the org zone. Planners always render in the **viewer's** zone. |
| D6 | Users get an optional **display name** (fallback: email), editable on a new `/settings` page; shown in org UI and reports. |
| D7 | "My planner" + personal analytics = **personal tasks + org tasks assigned to me** (not org tasks I merely created for others; not tasks from orgs I've left). |
| D8 | Scheduled/emailed reports later; the report builder/renderer take explicit inputs (no `HttpContext`) so a background job can reuse them. |
| D9 | Order: **Phase 1** org backend fixes → **Phase 2** export (personal PDF/CSV + guest print/CSV) → **Phase 3** org frontend (+ backend support) → **Phase 4** org & member reports. |

### Reconciled contracts (orchestrator)
- **Selection-based ranges for reports and org analytics.** The browser's date helpers (`src/lib/datetime.ts`) only know the *device* zone, so for anything bucketed in another zone the client sends the **selection** and the server resolves the half-open range in the right zone:
  `view=monthly|weekly|daily&year=2026&from=<month index 0-11 | ISO week>&to=<same>`
  (`monthly` → calendar year; `weekly`/`daily` → ISO week-year; `daily` uses `from=to=<week>`). Personal reports use the `X-Time-Zone` header; org/member reports use the org zone. The existing personal `/api/tasks/analytics` stays as-is.
- **One CSV format** for guest (browser) and account (server) exports — see §4.4.
- Report endpoints live under `/api/reports/...`.

## 2. Facts the plan rests on

- **QuestPDF 2026.9.1** (released 2026-09-25, targets net8/net10 → usable from .NET 9). Ships its own native Skia (~47.5 MB package, natives per OS/arch). Community License v3.0: free for individuals and businesses with **annual gross revenue under USD 1,000,000** (also charities, academia, OSS); **excludes public-sector bodies and publicly traded companies regardless of revenue**; 90-day grace period if eligibility is lost; no key — set `QuestPDF.Settings.License = LicenseType.Community`.
- QuestPDF draws **SVG natively** (`container.Svg(size => svg)`) → charts are hand-written SVG (bars + donut arcs); text via QuestPDF so it gets font fallback.
- Fonts: bundled Lato only; register embedded fonts; fallback lists (`FontFamily("Noto Sans", "Noto Sans Arabic", ...)`). Missing glyphs throw unless `Settings.ThrowOnMissingTextGlyphs = false`. RTL via `ContentFromRightToLeft()`; text shaping is claimed on the homepage only → **must be proven by a smoke test**.
- Tests can extract PDF text with **PdfPig 0.1.16** (Apache-2.0).
- Hosting: publish profile has no RuntimeIdentifier ("Any CPU") → portable publish ships natives for every OS/arch (+~47 MB). **App Service bitness (32/64-bit) is not in the repo — check the Azure portal.**
- SignalR: JWT setup (`Program.cs:81`) never reads `?access_token=` → browsers can't authenticate to `/hubs/organization` today. Hub groups come from JWT claims at connect time → stale for up to 15 min after create/join/leave; removed members keep receiving events.
- Members can't save admin-assigned org tasks today: `UpdateOrganizationTask.cs:76-80` requires the category to belong to the editor (categories are per user).

### 4.4 CSV format (shared by browser and server)
